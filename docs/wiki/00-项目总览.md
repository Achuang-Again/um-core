# 00 - 项目总览

## 1. 产品定位

**UM-Core** 是独立部署的**通用用户管理微服务**，对外提供 RESTful API。宿主业务系统通过 HTTP 调用，使用返回的 `user_id` 关联本地订单、评论等数据。

### 职责边界

| 包含 | 不包含 |
|------|--------|
| 账号注册、登录、登出、注销 | 订单、支付、商品域逻辑 |
| 用户资料与 JSON 扩展字段 | 宿主侧 RBAC 权限模型 |
| VIP 等级、开通/续费/升级、惰性过期 | 具体权益发放（由宿主根据 VIP 状态实现） |
| JWT 会话、登录风控 | 物理删除用户主表 |

## 2. 技术栈

| 类别 | 选型 |
|------|------|
| 语言 | Java 21 |
| 构建 | Maven 3.9.16 |
| 框架 | Spring Boot 3.2.5、Spring Security 6 |
| ORM | MyBatis-Plus 3.5.x |
| 数据库 | MySQL 8 |
| 缓存 | Redis |
| 迁移 | Flyway |
| API 文档 | springdoc-openapi 3 |

## 3. 仓库结构

```
um-core/
├── pom.xml                 # 父 POM（BOM、模块聚合）
├── um-common/              # 通用响应、异常、错误码
├── um-domain/              # 领域枚举、值对象
├── um-infrastructure/    # PO、Mapper、Redis、JWT
├── um-profile/             # 用户资料应用服务
├── um-vip/                 # VIP 应用服务
├── um-auth/                # 认证应用服务
├── um-api/                 # REST Controller、Security
├── um-bootstrap/           # 启动类、配置、Flyway
└── docs/                   # 架构说明、规约、本 Wiki
```

## 4. 运行依赖

- **MySQL**：库名默认 `um_core`，Flyway 自动执行 `db/migration`
- **Redis**：Token、验证码、登录锁定、幂等键
- 配置项前缀：`UM_*`，详见 [modules/um-bootstrap.md](modules/um-bootstrap.md)

## 5. 统一 API 约定

- 前缀：`/api/v1/um`
- 响应：`ApiResponse<T>{ code, message, data, traceId, timestamp }`，`code=0` 为成功
- 认证：`Authorization: Bearer <accessToken>`
