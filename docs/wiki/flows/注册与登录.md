# 流程：注册与登录

## 1. 用户名注册

```mermaid
sequenceDiagram
    participant C as 客户端
    participant AC as AuthController
    participant Reg as RegisterApplicationService
    participant UR as UserRepository
    participant Prof as ProfileApplicationService
    participant Login as LoginApplicationService

    C->>AC: POST /auth/register/username
    AC->>Reg: registerByUsername(cmd)
    Reg->>Reg: validatePassword, existsUsername
    Reg->>UR: save(sys_user) BCrypt密码
    Reg->>Prof: initProfile(userId)
    Reg->>Login: issueTokens(userId)
    Login-->>C: access + refresh Token
```

### 关键步骤

1. 密码长度 ≥ 8
2. 用户名唯一性检查
3. `ext_data` 写入 `registerType=USERNAME`、`registerIp`
4. 同事务：用户 + 资料初始化
5. 注册成功即自动登录

**实现类**：`RegisterApplicationService.registerByUsername`

---

## 2. 手机号注册

```mermaid
flowchart TD
    A[POST /auth/sms/send] --> B[SmsCodeService 存 Redis 5min]
    C[POST /auth/register/phone] --> D{验证码正确?}
    D -->|否| E[AUTH_INVALID_SMS_CODE]
    D -->|是| F[创建用户 phone 绑定]
    F --> G[initProfile + issueTokens]
```

**实现类**：

- `SmsCodeApplicationService.sendLoginCode`
- `RegisterApplicationService.registerByPhone`

---

## 3. 登录

```mermaid
flowchart TD
    Start[POST /auth/login] --> Lock{账号锁定?}
    Lock -->|是| E1[AUTH_ACCOUNT_LOCKED]
    Lock -->|否| Find[按 username 或 phone 查用户]
    Find -->|不存在| E2[AUTH_INVALID_CREDENTIALS]
    Find --> Status{status 正常?}
    Status -->|注销/禁用| E3[对应错误码]
    Status --> Pwd{BCrypt 匹配?}
    Pwd -->|否| Fail[recordFailure + E2]
    Pwd -->|是| Geo{异地检测开启?}
    Geo -->|IP 变化| E4[AUTH_GEO_RISK]
    Geo --> Ok[clearFailures + 更新 lastLoginIp]
    Ok --> Vip[VipStatusResolver.resolve]
    Vip --> Token[issueTokens]
```

### 多端 SSO 说明

- 每个 `deviceId` 独立一条 Refresh：`um:refresh:{userId}:{deviceId}`
- 同用户多设备可同时在线
- 踢人：`POST /auth/kick-all` 删除所有 refresh 键

**实现类**：`LoginApplicationService.login`

---

## 4. 刷新 Token

1. 校验 `um:refresh:{userId}:{deviceId}` 与请求中 refreshToken 一致
2. **轮换**：删除旧 refresh，签发新 access + refresh
3. 旧 access 未强制黑名单（依赖短 TTL）

**实现类**：`LoginApplicationService.refresh`
